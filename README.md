# 🌸 FNP Sales Analysis Dashboard — Excel Data Analytics Project

This project focuses on data analysis and dashboard creation for **Ferns and Petals (FNP)**, a leading gifting platform in India. The goal is to extract actionable insights from sales, customer, and product data to optimize FNP's business strategies.

## 📊 Project Objective

Analyze FNP’s sales data to uncover insights on:
- Customer behavior
- Product performance
- Occasion-wise trends
- Order-to-delivery time
- City-wise sales distribution

The outcome is an **interactive Excel dashboard** using **Power Query**, **Power Pivot**, and **Pivot Tables**.

---

## 🔧 Tools & Techniques Used

- **Excel**: Power Query, Power Pivot, Pivot Tables, Data Modeling
- **Data Cleaning**: Duplicate removal, format correction, missing value handling
- **Data Modeling**: Relationships between Orders, Products, Customers, and Dates
- **Visualization**: KPIs, bar charts, slicers, pivot graphs for dynamic analysis
